# 予約一覧 時間帯分け

システムから出力した「受講生予約一覧」（.xlsx）を、朝・昼・晩の3つのファイルに分けるWebアプリです。

**アプリ:** https://selo-git.github.io/yoyaku-jikantai-split/

## 使い方

1. 上のURLを開く
2. 受講生予約一覧の .xlsx をドラッグ＆ドロップ（またはクリックして選ぶ）
3. 各時間帯（朝・昼・晩）の「印刷」ボタンでそのまま印刷する。Excelファイルが必要なときはその下の「Excelで保存」
   - 「まとめて印刷」で朝・昼・晩を続けて印刷（時間帯ごとに改ページ）
   - 「3つともExcelで保存」でまとめて保存
   - 「分けずに1つにまとめる」の「印刷」「Excelで保存」で、朝・昼・晩に分けずに全員を1つの一覧にする（時間帯をまたぐ人も1回だけ）

開いた直後は、架空の受講生データのサンプルが表示されます。

## 印刷

- A4の横・縦を「印刷の向き」で選べる（横：文字 8.5pt／縦：文字 約6.2pt。選んだ向きはブラウザに記憶）
- 「印刷の枚数」で「1枚に収める」〜「10枚以内に収める」を選ぶと、その枚数に収まるまで文字を小さくする（まとめて印刷では時間帯ごとの枚数）
  - 印刷の直前に実際に表を組んで、受講生ごとの高さを測る。印刷と同じようにページへ割り付けて（見出しは各ページにくり返し、1人ぶんはページをまたがない）枚数を数え、指定の枚数に収まるいちばん大きな文字の大きさを選ぶ。セルの内側の余白も一緒に縮める
  - もともと指定の枚数に収まるときは、文字の大きさはそのまま
  - 枚数が少なく人数が多いと文字がかなり小さくなる。それでも収まらないときは画面に知らせる
- 「次講座③」「当日の詳細メモ」は初期設定では印刷しない。「印刷に入れる列」のチェックで入れられる（Excelで保存するファイルには全部の列が入る）
- ブラウザが余白に付ける URL・日付・ページ名は印刷しない（用紙の余白を0にして、余白は表の側で取っている）
- 見出し（対象日・列名）は各ページにくり返し、右上に時間帯と人数を表示
- 灰色・白の色分け、点線の罫線は Excel と同じ
- ID・氏名・時間・日時は1行に収め、備考の列は最低24文字分の幅を確保して折り返す
- 次講座は文字を少し小さく（85%）して1行に収める。備考の幅が足りない日は 70% まで小さくする。それでも足りないときは確認事項・エリアの列を縮めて、その中で折り返す
- 列幅は印刷の直前に、実際に使われるフォント（Windows はメイリオ UI、Mac は BIZ UDPゴシック）で文字幅を測って決める
- 「当日の詳細メモ」を印刷に入れたときは、手書き用に一定の幅を残す
- 受講生1人ぶん（本行と備考の行）は、なるべく同じページに収める
- 色分けが印刷されないときは、印刷画面の「詳細設定」で「背景のグラフィック」をオンにする

## 分け方

| 時間帯 | 範囲 |
| --- | --- |
| 朝 | 〜13:00 |
| 昼 | 13:00〜17:00 |
| 晩 | 17:00〜20:30 |

- 区切りの時刻は画面で変えられます（設定はブラウザに記憶されます）。
- 時間帯をまたぐ予約（例：11:00〜15:00）は、既定では両方の一覧に入ります。「開始時間の一覧だけ」にも切り替えられます。

## 書き出すファイル

- ファイル名は `元のファイル名_朝.xlsx` `_昼.xlsx` `_晩.xlsx`（分けずにまとめたときは `_全員.xlsx`）
- 罫線・フォント・結合セル・印刷設定（A4横・横1ページに収める）・ウィンドウ枠の固定は元のファイルのまま
- 受講生ごとの灰色・白の色分けは、各ファイルの先頭から振り直し
- 列幅は残った内容に合わせて縮める
- A4で印刷しても長い備考が見切れないように：
  - 備考（自由記述欄・予約/受講履歴・イベント）や講座名は、列の幅のまま折り返して全文を表示（隣の列にははみ出さない）
  - 行の高さは折り返した行数に合わせて設定（メイリオUI 11pt の文字幅から計算）。複数行になる行は上揃え
  - 備考の先頭・末尾の空行は詰める
- 備考登録日時は「10/13」のように月/日だけを表示する（セルの値は日付・時刻のままで、表示形式だけ mm/dd にする）。印刷も同じ
  - 「当日の詳細メモ」の列は手書き用に空けたまま
- ほかの時間帯の受講生の情報はファイルの中に残らない

## データの扱い

- ファイルはブラウザの中だけで処理し、どこにも送信しません。外部から読み込むのは JSZip（cdnjs）と Google Fonts だけです。
- このリポジトリに実際の予約一覧ファイルを入れないでください（`.gitignore` で `*.xlsx` を除外しています）。
