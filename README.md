# 予約一覧 時間帯分け

システムから出力した「受講生予約一覧」（.xlsx）を、朝・昼・晩の3つのファイルに分けるWebアプリです。

**アプリ:** https://selo-git.github.io/yoyaku-jikantai-split/

## 使い方

1. 上のURLを開く
2. 受講生予約一覧の .xlsx をドラッグ＆ドロップ（またはクリックして選ぶ）
3. 「朝を印刷」などのボタンでそのまま印刷する。Excelファイルが必要なときは「Excelで保存」
   - 「まとめて印刷」で朝・昼・晩を続けて印刷（時間帯ごとに改ページ）
   - 「3つともExcelで保存」でまとめて保存

開いた直後は、架空の受講生データのサンプルが表示されます。

## 印刷

- A4の横・縦を「印刷の向き」で選べる（横：文字 8.5pt／縦：文字 約6.2pt。どちらも11列すべてを印刷。選んだ向きはブラウザに記憶）
- 見出し（対象日・列名）は各ページにくり返し、右上に時間帯と人数を表示
- 灰色・白の色分け、点線の罫線は Excel と同じ
- ID・氏名・時間・日時は1行に収め、備考の列は最低24文字分の幅を確保して折り返す。足りないときは確認事項・エリア・次講座の列を縮めて、その中で折り返す
- 「当日の詳細メモ」の列は手書き用に一定の幅を残す
- 受講生1人ぶん（本行と備考の行）は、なるべく同じページに収める
- 色分けが印刷されないときは、印刷画面の「詳細設定」で「背景のグラフィック」をオンにする

## 分け方

| 時間帯 | 範囲 |
| --- | --- |
| 朝 | 〜13:00 |
| 昼 | 13:00〜17:00 |
| 晩 | 17:00〜20:30 |

- 区切りの時刻は画面で変えられます（設定はブラウザに記憶されます）。
- 時間帯をまたぐ予約（例：11:00〜15:00）は、既定では両方の一覧に入ります。「開始時間の一覧だけ」にも切り替えられます。

## 書き出すファイル

- ファイル名は `元のファイル名_朝.xlsx` `_昼.xlsx` `_晩.xlsx`
- 罫線・フォント・結合セル・印刷設定（A4横・横1ページに収める）・ウィンドウ枠の固定は元のファイルのまま
- 受講生ごとの灰色・白の色分けは、各ファイルの先頭から振り直し
- 列幅は残った内容に合わせて縮める
- A4で印刷しても長い備考が見切れないように：
  - 備考（自由記述欄・予約/受講履歴・イベント）や講座名は、列の幅のまま折り返して全文を表示（隣の列にははみ出さない）
  - 行の高さは折り返した行数に合わせて設定（メイリオUI 11pt の文字幅から計算）。複数行になる行は上揃え
  - 備考の先頭・末尾の空行は詰める
  - 「当日の詳細メモ」の列は手書き用に空けたまま
- ほかの時間帯の受講生の情報はファイルの中に残らない

## データの扱い

- ファイルはブラウザの中だけで処理し、どこにも送信しません。外部から読み込むのは JSZip（cdnjs）と Google Fonts だけです。
- このリポジトリに実際の予約一覧ファイルを入れないでください（`.gitignore` で `*.xlsx` を除外しています）。
